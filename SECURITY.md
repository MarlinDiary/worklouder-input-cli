# Security policy

WorkLouderCTL handles keyboard configuration, host-side actions, application
paths, and command payloads. Treat configuration and backup files as potentially
sensitive.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/MarlinDiary/worklouder-input-cli/security/advisories/new)
for this repository. For a non-sensitive bug, use the structured bug-report
form.

Include the affected version or commit, operating system, Input version,
firmware version, device model, reproduction steps, and expected impact. Remove
credentials, private commands, Smart Action text, device identifiers, and local
paths from reports and fixtures.

## Current support status

The current distribution is a source-build prerelease; signed and notarized
binaries begin with the first published version tag. The current `main` branch
receives security fixes. Versioned security-support windows begin with the first
published release and will be documented here by release line.
