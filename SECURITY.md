# Security policy

WorkLouderCTL will handle keyboard configuration, host-side actions, application
paths, and command payloads. Treat configuration and backup files as potentially
sensitive.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when it is
available. For a non-sensitive bug, open a normal GitHub issue.

Include the affected version or commit, operating system, Input version,
firmware version, device model, reproduction steps, and expected impact. Remove
credentials, private commands, Smart Action text, device identifiers, and local
paths from reports and fixtures.

## Current support status

The project is pre-alpha and has no released binary. Security support begins
with the first published release and will be documented here by release line.
